# Project instructions

This workspace is for the website for **Minimal Timer**, a native macOS menu-bar app for activity tracking and Pomodoro sessions. Read [README.md](README.md) for product context and upstream links before making changes.

- Keep website work in this workspace. The app lives in the separate [timer-app repository](https://github.com/marandicimihai/timer-app). If the sibling checkout at `../timer-app` exists, use it as a local reference.
- Use the upstream README and app source for product behavior, and the published GitHub release for download assets and release-specific claims. Verify compatibility, signing and notarization status, and download availability when changing public install copy.
- Use **Minimal Timer** in public-facing copy. Keep the copy direct and consistent with the app’s focus on doing one thing at a time. Use screenshots and artwork from the real app where available, and keep them aligned with the release they represent.
- Point download and feedback links to the official upstream destinations listed in the README. Keep any first-launch guidance specific to Minimal Timer and consistent with the published release instructions.
